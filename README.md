# أذكاري 🤲 | أذكار الصباح والمساء

موقع عربي (RTL) أنيق لعرض أذكار الصباح والمساء.

## المزايا
- 🌅🌙 تبويبا أذكار الصباح والمساء (20 ذكراً لكل قسم)
- ✍️ خط [ثمانية](https://github.com/EngDawood/thmanyah-font-web) الرسمي عبر CDN
- 🔍 بحث فوري + إخفاء المنجز
- 🤲 مسبحة إلكترونية لكل ذكر مع شريط تقدم وحفظ تلقائي (localStorage)
- 🌙☀️ وضع ليلي / نهاري
- 👴 وضع كبار السن + أزرار تكبير/تصغير الخط (A+ / A−)
- 📱 متجاوب مع الجوال + تاريخ هجري

## التشغيل محلياً
افتح `index.html` في المتصفح مباشرة — لا يحتاج بناء أو سيرفر.

## النشر على GitHub Pages
بعد رفع المشروع على GitHub:
`Settings → Pages → Deploy from a branch → main → / (root)`

## التقنيات
HTML + CSS + JavaScript (بدون مكتبات — يعمل أوفلاين عدا خط ثمانية عبر CDN).
